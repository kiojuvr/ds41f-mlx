## Failures found while establishing the verifier

Early attempts exposed reference-harness, not runtime, problems: checkpoint and
recipe tokenizer identities were conflated; in-process fixture imports polluted
paths; a script entry point could select a prior editable clone; explicit checkpoint
was omitted; current executable source needed its normal fresh seal. Those issues
were corrected by separate identities, subprocess isolation, module entry points,
current editable installation and normal seal before the final independent run.
The identity failures were not bypassed. A mutation run parallel to real model
loading was killed; the final sequential campaign has complete assertion failures.
An additional explicit negative fixture was needed to detect forbidden quiescence
work—existing successful drains alone did not demonstrate that rejection. It now
forms part of R1. No runtime semantic contract was weakened to obtain PASS.

## Limits and next step

The declared M41 exclusions all remain: default/generalized MTP, concurrent,
remote/browser/Rust MTP application, persistence/restart/rollover, arbitrary tool
schemas/sampling/stops, distributed/crash-safe effects and long-context MTP.
OFF's historical deployment/provenance checkout barrier remains operator-delivery
debt; the **reference command** itself no longer needs it. Full temporary substrate
replacement is not scheduled. No extraction or `ds41f-runtime` was created.

R1 is an executable finite development oracle, not all-input formal verification.
Official semantics remain higher authority. New math/backends/checkpoints/protocol
or discovered reference defects require official-authority investigation and affected
qualification/R2, not preservation of a golden bug. M43 may now design a deterministic
one-way promotion using this reference identity and qualification evidence.
