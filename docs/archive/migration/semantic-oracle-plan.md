This is the forward plan for replacing oMLX-derived correctness evidence with official-reference-derived semantic fixtures.

- Native model-math expansion remains frozen beyond the explicitly validated bounded primitive set.
- Validated native bounded primitives are:
  - `ParallelEmbedding.forward` / BF16 embedding gather, bit-exact within fixture scope;
  - BF16 dense linear on the non-quantized `linear()` / `F.linear` branch, bit-exact within fixture scope;

## Fixture provenance classes

Every future fixture must declare one of:

| Class | Meaning | May gate official correctness? |
| --- | --- | --- |
| `official_checkpoint_raw_bits` | Direct raw tensor/config/tokenizer bytes or exact slices | Yes, for model data only |
| `official_reference_derived` | Expected values generated from pinned official reference code with documented function/file/SHA | Yes, within declared scope |
| `independent_arithmetic_contract` | Expected values generated by a documented independent operation over official tensors | Yes, for that primitive only |
| `architecture_only` | DwarfStar topology/lifetime/submission fact | No model semantics claim |
| `omlx_compatibility_reference` | Expected values from oMLX execution | No |
| `historical_unknown` | Insufficient provenance | No |

## Minimum stage order

1. **Authority review gate**
   - Verify the local official reference snapshot and M1 HF revision against official DeepSeek release material.
   - Record reviewed file list and hashes.
   - Record function-level source spans with `tools/record_official_reference_review.py` / `docs/official-reference-review.md`.
   - No numerical oracle is produced at this step.

2. **Tokenizer/input authority**
   - Define prompt/token encoding fixtures from official tokenizer/config only.
   - Do not use oMLX processor output as the expected result unless labeled compatibility-only.

3. **Embedding stage**
   - Already clean for raw BF16 token gather.
   - `docs/parallel-embedding-semantics-contract.md` records the manual `ParallelEmbedding.forward` operation contract.
   - `artifacts/parallel-embedding-semantics-contract.json` is contract metadata only.
   - `artifacts/parallel-embedding-official-reference-fixture.json` is the first `official_reference_derived` fixture for sharded embedding masking/all-reduce semantics, generated without oMLX/PyTorch/MLX/native execution.
   - `artifacts/native-embedding-official-reference-validation.json` validates the existing native BF16 embedding gather primitive against that fixture, within bounded token/dim scope.

4. **Dense BF16 linear stage**
   - Current primitive is clean as `official_reference_derived_independent_arithmetic_contract`:
     `out = input_bf16_as_f32 @ weight_bf16_as_f32.T`, F32 output.
   - `docs/bf16-linear-semantics-contract.md` records the reviewed non-quantized `linear()` / `F.linear` branch and declared F32 arithmetic contract.
   - `artifacts/native-linear-official-reference-validation.json` validates the existing native BF16 linear primitive against that fixture.
   - It is not yet a claim about full-layer dtype behavior.

5. **RMSNorm stage**
   - `docs/rmsnorm-semantics-contract.md` records the reviewed `RMSNorm.forward` source span and a bounded official-reference-derived fixture.
   - `artifacts/rmsnorm-official-reference-fixture.json` is generated without oMLX/PyTorch/MLX/native execution.
   - `artifacts/native-rmsnorm-official-reference-validation.json` validates the native BF16 RMSNorm primitive within the predeclared `max_bf16_ulp_lte = 1` tolerance.

6. **Rotary helper stage**
   - `docs/rotary-semantics-contract.md` records reviewed `precompute_freqs_cis` / `apply_rotary_emb` source spans and bounded no-YaRN plus YaRN fixtures.
   - `artifacts/rotary-official-reference-fixture.json` and `artifacts/rotary-yarn-official-reference-fixture.json` are generated without oMLX/PyTorch/MLX/native execution.
   - `artifacts/native-rotary-official-reference-validation.json` validates the native Metal-backed no-YaRN precompute/apply/inverse data path within the predeclared `max_abs_error_lte = 1e-6` and `max_f32_ulp_error_lte = 64` tolerance.
   - `artifacts/native-rotary-yarn-official-reference-validation.json` validates the same native path with the YaRN interpolation branch enabled for `original_seq_len=16` within the same tolerance.

7. **Remaining reference-derived primitive stages**
   - Expand rotary only if larger/model-shape rotary fixtures are needed, or select the next simple reviewed primitive.
   - Current reconciliation candidate before entering attention internals: `ParallelHead.forward` bounded output-head/read-logits seam.
   - Each stage needs an explicit dtype/rounding contract and bounded fixture.

8. **Semantic boundary design / attention Stage 1a**
   - `docs/m2-semantic-boundary-design.md` defines the first attention-internal Stage 1 as Q-prelude through rotary, stopping before sparse attention/cache/output projection/HC.
   - Because official layer-0 attention projection weights are FP8, attention-internal Stage 1 implementation begins with Stage 1a: reviewed FP8 linear/GEMM semantics and native validation.
   - This does not make FP8 attention the only allowed next primitive; a bounded `ParallelHead.forward` fixture may be done first because it closes the output-head seam without entering attention/MoE/Engram/HC.

9. **Complex semantics stages**
   - Attention sparse kernels, Engram, compressor/indexer, MoE routing, quantized FP4 kernels, Hyper-Connections, DSpark/MTP, and cache publication require separate review plans.
   - Do not infer these from matching oMLX cache/logits.

## Required fixture metadata

Future official semantic fixtures must follow `docs/official-fixture-metadata-schema.md` and include:

```json
{
  "classification": "official_reference_derived | independent_arithmetic_contract | official_checkpoint_raw_bits",
  "not_omlx_derived": true,
  "checkpoint": "...",
  "official_reference": {
    "file": "inference/model.py",
    "sha256": "...",
    "function_or_class": "..."
  },
  "operation_contract": "precise operation and dtype/rounding statement",
  "inputs": "tensor names/slices/dtypes/digests",
  "expected_provider": "how the expected value was generated",
  "non_claims": ["no full-model correctness unless explicitly scoped"]
}
```

## Forbidden promotions

- `matches oMLX _forward` -> official correctness.
- `matches oMLX logits` -> official logits oracle.
- `matches oMLX cache/state/frontiers` -> official cache/state semantics.
- `DwarfStar topology matches` -> official model math correctness.
- Performance success -> qualification.
