# Browser Chat interface — retired

The bundled Browser Chat and Chat Server are retired. There is no supported
Browser launch, frontend, application conversation store or tool executor.
Use external clients with Runtime's native Chat Completions or Messages APIs.
The TUI is solely an [operator console](operator-chat.md), not a Chat client.
No replacement Harness is bundled. Successful model inference does not prove
comprehensive Agent/Harness compatibility.
